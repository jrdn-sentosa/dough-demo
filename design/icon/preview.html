Dough! app icon

Each crop uses the source file that makes that icon. The rounded square and square crops use the larger artwork. The circle and the Android rounded square use the maskable artwork, which keeps a margin inside the safe zone.

Behind the icon

The dashed ring is the middle 80%, the safe zone Android keeps for any mask. The dotted ring is 72%, the limit the maskable artwork is held to, so its farthest point sits inside it. The iPhone crop uses a corner radius of about 22% of the width.
